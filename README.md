## Overview

Assembly X is an independent interactive mathematics-learning prototype for all-age beginners working at approximately Grade 6. It explores how operation order, grouping, and the distributive property affect the meaning of algebraic expressions.

The experience uses a literal fabrication system: the learner assembles an operation sequence, runs it, observes the resulting inventory, and revises the program. The system's behavior provides the primary feedback rather than relying on generic right-or-wrong messages.

## Learning goals

Learners are invited to:

- Interpret an expression as a sequence of actions
- Distinguish \(2(x+3)\) from \(2x+3\)
- Connect grouping symbols with the scope of an operation
- Recognize \(2(x+3)\) and \(2x+6\) as equivalent expressions
- Use a counterexample to disprove a false equivalence claim
- Explain equivalence structurally rather than relying on one matching test

## Standards alignment

The prototype is primarily aligned with:

- CCSS 6.EE.A.2: Write, read, and evaluate expressions
- CCSS 6.EE.A.3: Apply properties of operations to generate equivalent expressions
- CCSS 6.EE.A.4: Identify when two expressions are equivalent

## Prototype structure

The seven-level vertical slice progresses through:

1. Operation order with numerical inputs
2. The same operations in a different order
3. A variable represented by a sealed quantity
4. Grouping and multiplication scope
5. Equivalent expressions
6. Counterexamples
7. A hidden-test transfer challenge

## Design focus

This prototype was created to explore:

- Problem-first learning
- Visual and behavioral feedback
- Misconception-responsive explanations
- Concrete-to-symbolic progression
- Mobile and keyboard-accessible interaction
- Validation across hidden input values
